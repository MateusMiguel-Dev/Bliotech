# Bliotech

Sistema web de gerenciamento de biblioteca, desenvolvido como projeto de interface e desenvolvimento front-end.

## Sobre o projeto

O Bliotech simula uma plataforma administrativa para controle de livros, usuários, empréstimos, multas e devoluções. O projeto utiliza uma estrutura de navegação por módulos e um dashboard com indicadores para facilitar o acompanhamento da operação.

## Principais recursos

- Dashboard administrativo
- Cadastro e gerenciamento de livros
- Gerenciamento de usuários
- Controle de empréstimos
- Consulta de multas e atrasos
- Fluxo de devolução
- Área de ajuda, suporte e contato
- Interface com navegação por módulos

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

```text
Bliotech/
├── css/
├── img/
├── pag/
├── index.html
└── login.html
```

## Como executar

Abra o `index.html` diretamente no navegador ou utilize Live Server para executar o projeto localmente.

## Objetivo

Projeto desenvolvido para praticar construção de interfaces administrativas, arquitetura de informação, navegação entre telas e organização de dados em sistemas web.
